五點口訣

轉到這五個位置時，高度是多少？每一列點一個答案，圖上會出現你選的點。全部選完按「檢查」。

一直轉，就一直重複

轉一圈回到原位，所以 0 到 2π 這段波浪可以一直複製貼上。每一段長 2π，這叫做週期。

五個特性

課本的五個特性，都是從波浪圖「看」出來的。左邊是課本寫法，右邊是白話。

是非題：對的選 O，錯的選 X

找出範圍

sin x < 0 就是高度是負的，也就是波浪在 x 軸下面。sin x > 0 就是在 x 軸上面。
