如何新增教材

在下方 <script> 裡的 materialsData 陣列新增一筆資料即可,格式如下:

{
  grade: 'g10', // g10 / g11 / g12 / basic / math
  title: '教材名稱',
  unit: 'Unit 3', // 單元或課次,沒有可留空字串
  tags: ['文法','時態'], // 標籤,用於搜尋
  url: '連結網址' // CodePen 的 Preview Only 連結,或本站內的相對路徑(例如 math/xxx.html)
}

目前清單裡的項目是範例,請替換成你實際的 CodePen 連結。建議用 Preview Only 模式產生的連結(Copy Link with Layout),學生點開才是乾淨的畫面,不會看到程式碼。若教材是放在這個repo裡的獨立html檔(例如數學工具),url 直接填相對路徑即可,不用完整網址。
